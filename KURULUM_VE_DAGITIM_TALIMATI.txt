── ADIM 1 — DİZİN AYARI ────────────────────────────────────────

fikstur_talep2.py dosyasını aç.
70. satırda DEFAULT_BASE_DIR satırını bul ve istediğin dizine göre değiştir:

  Yerel dizin örneği:
    DEFAULT_BASE_DIR = Path(r"C:\FixtureRequests")

  Ağ sürücüsü örneği:
    DEFAULT_BASE_DIR = Path(r"\\SUNUCU\Paylasim\FixtureRequests")

NOT: Seçtiğin klasörün yazma iznine sahip olduğundan emin ol.


── ADIM 2 — BAĞIMLILIK KURULUMU (Windows) ──────────────────────

Komut İstemi'ni (cmd) aç ve sırasıyla çalıştır:

  pip install PySide6
  pip install openpyxl
  pip install reportlab
  pip install pywin32

Hepsi birden:
  pip install PySide6 openpyxl reportlab pywin32


── ADIM 3 — ÖNCE PYTHON İLE TEST ET ───────────────────────────

Uygulamayı exe yapmadan önce Python ile çalıştır:

  python fikstur_talep2.py

Kontrol listesi:
  [ ] Uygulama açıldı
  [ ] Form dolduruldu
  [ ] "Kaydet ve Gönder" butonuna basıldı
  [ ] Outlook maili gönderdi (oguzhanb@aselsan.com.tr)
  [ ] Belirtilen dizinde klasör oluştu
  [ ] Excel log dosyası oluştu (fikstur_talep_log.xlsx)
  [ ] PDF özeti oluştu


── ADIM 4 — EXE OLUŞTURMA ──────────────────────────────────────

PyInstaller'ı kur:
  pip install pyinstaller

fikstur_talep2.py dosyasının bulunduğu klasörde cmd aç ve çalıştır:

  pyinstaller --onefile --windowed --name "FiksturTalep" ^
    --collect-all win32com ^
    --collect-all pythoncom ^
    --collect-all win32 ^
    --hidden-import win32timezone ^
    --hidden-import pywintypes ^
    fikstur_talep2.py

NOT: Yukarıdaki komut mail gönderimi ve sürükle-bırak özelliklerinin
     EXE'de düzgün çalışması için gerekli pywin32 DLL'lerini toplar.

Oluşan exe dosyasının konumu:
  dist\FiksturTalep.exe


── ADIM 5 — DAĞITIM ────────────────────────────────────────────

Kullanıcılara sadece "FiksturTalep.exe" dosyasını ver.

  - Karşı tarafta Python kurulu OLMASI GEREKMİYOR.
  - Başka hiçbir kurulum GEREKMEZ.
  - Sadece .exe'yi çift tıklayıp çalıştırıyorlar.
